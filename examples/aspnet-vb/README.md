# ASP.NET (VB.NET) example — planned (v0.3.0)

Not implemented yet. Contributions welcome — see [CONTRIBUTING.md](../../CONTRIBUTING.md).

VB.NET does not have the same first-class support in modern ASP.NET Core
that C# does. This example will target the smallest honest, runnable
setup suitable for maintaining an existing VB.NET ASP.NET application
(likely classic ASP.NET Web API / Web Forms rather than ASP.NET Core),
and will say so explicitly rather than implying parity with the C#
example.
